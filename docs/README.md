# Daydream user guide

New to Daydream? Start with [installation and your first asset](../README.md).

| I want to… | Read this |
| --- | --- |
| Create, preview, approve or add artwork | [Your assets](REVIEW.md) |
| Make a character, prop or animation | [Sprites and animations](SPRITE_WORKFLOW.md) |
| Build walls, floors and transitions | [Environment tiles](TILESETS.md) |
| Add blocking shapes, ramps or platforms | [Collisions](COLLISIONS.md) |
| Paint a generated layout in Godot | [Editor-visible layouts](EDITOR_LAYOUTS.md) |
| Keep old versions or safely update artwork | [Versions and updates](ASSET_LIFECYCLE.md) |
| Run the game or preview a single asset | [Preview and playtest](PREVIEW.md) |
| Fix a setup or workflow problem | [Troubleshooting](TROUBLESHOOTING.md) |

**Everyday commands:** `/assets` to manage artwork, `/preview game` to playtest,
and `/preview stop` to finish. Use `/preview status` when a game fails to start.

Building Daydream itself? The [contributor guide](DEVELOPMENT.md) links the
implementation references and validation records.
